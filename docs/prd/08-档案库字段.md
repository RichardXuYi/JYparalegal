# 档案库就是本机文件夹

不再使用公司 MySQL。默认目录是后端进程旁的 `./data/archive`，可用环境变量 `ARCHIVE_DIR` 改掉。

每个租户一个子目录，下面每个案卷一个文件夹：

| 路径 | 内容 |
|---|---|
| `{租户}/{案卷}/case.json` | 立场、摘要、状态 |
| `{租户}/{案卷}/files/` | 上传的原件 |
| `{租户}/{案卷}/files.json` | 文件名、指纹、解析状态、切片正文 |
| `{租户}/{案卷}/hearing-{id}.json` | 五个槽、笔录、本槽检索片段 |

页面看到的字段名不变：`stance`、`summary`、`fileName`、`parseStatus`、`role_code`、`plan_text`、`excerpt`。

仓库里的 `公司档案库/V1__archive_and_moot.sql` 先不用执行。
