# 验收与范围外

A 到 C 不需要模型密钥，先做完。没有密钥时，D 和 E 停在页面上展示已组装的消息，不把假发言说成开过庭。

| 步骤 | 位置 | 验收 |
|---|---|---|
| A. 文件夹与上传 | `./data/archive` | 平台库表数量不变。上传一份有文字层的 docx 或 pdf 后，该案卷目录里有原件和 `files.json`。`jy_financial` 无新表 |
| B. 检索 | 数据平面 | 用「第×条」能返回该段原文和文件名。别的案卷号结果为空。`NO_TEXT` 的文件不出现 |
| C. 队列 | 数据平面，commit 可用固定假文 | 五个槽能走完。刷新后从最后一条已提交的下一槽继续。重复 commit 被拒绝 |
| D. 单槽发送 | 宿主 | 被告槽发出时，只有被告的会话文件有新消息。审判长、书记员、陪审员、原告的会话没有这句 |
| E. 页面 | 宿主 + `/moot` | 上传合同后跑完五个槽。笔录可在庭审视图回看。结案后六个 session 的 jsonl 已删除。记忆文件与开庭前快照一致 |
| F. 技能列表 | 宿主 | 某角色 `skills` 写成 `[]` 后，`openclaw.json` 里该条目是空数组。不要求此时已有庭审 Skill 文件 |

## 已知限制

| 情况 | 本期行为 |
|---|---|
| 扫描件没有文字层 | 列表标 `NO_TEXT`，可以预览，不能当检索依据 |
| 换一种说法描述同一条款 | 关键词可能漏掉。不配一个「看起来像」的句子充数 |
| 档案目录不存在 | 第一次写入时创建 `./data/archive` |
| Skill 未交付 | 开庭不阻塞 |
| 发言被当成法律意见 | 页面和笔录上的固定声明 |
