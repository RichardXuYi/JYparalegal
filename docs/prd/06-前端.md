# 前端

入口是已有路由 `/moot`：`studio-web` 与 `studio-frontend` 的 `src/pages/MockCourt/index.tsx`。本期不新增顶层导航。需要可收藏的地址时再用 `/moot/:caseId`。

桌面壳与 web 一样是正式入口。两边的驱动做同一件事：开庭登记六个会话、超时跳过、结案删除会话并恢复这一场的记忆快照。页面不调用 `chat.sendWithMedia`。

`docs/demo/mock-court-demo.html` 按本期三个视图和五个发言槽演示。不要把旧稿里的七维页、隐藏推演、北大法宝做成本期功能。

## 三个视图

| 视图 | 内容 |
|---|---|
| 案卷 | 列表、新建。新建可选一个 `sign_task`，也可以不选，只上传文件。填写案情摘要和立场 |
| 档案 | 上传、解析状态、打开原件。一份文件一行 |
| 庭审 | 上方五个槽和当前角色。中间是已 `commit` 的发言，一条一块，不用聊天气泡。下方只在 `awaitHuman` 时出现输入框 |

庭审页和笔录固定一句：模拟发言，不是裁判文书。

条号若未出现在本槽检索摘录中，旁边标「未在本槽片段中出现」。

## 页面不做什么

- 不调用 `chat.sendWithMedia`
- 不决定下一槽
- 不在浏览器里保存合同正文
- 第二个窗口只看同一场的进度，不另起一场生成

事件来自宿主：`slot-started`、`delta`、`slot-committed`、`await-human`、`hearing-closed`。

## 样式

沿用法律页已有的 `LegalPageHeader` 和表面、字号令牌。文案中文，与现有占位页一致。若该包要求文案走 i18n，再补 `zh` 以及仓库里已经在用的其他语言键，不在本期翻译法庭专用词。
